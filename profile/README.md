## About Neptunium

Neptunium is an open source software startup focused on creating useful, reliable, and accessible products for everyday users and developers. We explore ideas across desktop, mobile, and web development, then turn the most promising ones into practical projects that people can use, inspect, improve, and make their own.

Our work is guided by a simple belief: great software should be understandable, respectful of its users, and available across the platforms people already use.

## What we build

| Area | Focus |
| --- | --- |
| **Windows** | Native and cross-platform desktop applications, utilities, and productivity tools. |
| **Android** | Mobile applications designed for clarity, performance, and real-world usefulness. |
| **Linux** | Open desktop software, developer tools, command-line utilities, and community-driven projects. |
| **Web** | Fast, accessible web applications and services that complement our desktop and mobile projects. |
| **Developer tools** | Libraries, APIs, automation tools, templates, and documentation that help people build better software. |

## Our approach

### Open by default

We believe open source works best when people can understand how a project works and participate in its direction. Whenever possible, our source code, documentation, issue tracking, and development discussions are public.

### Designed for people

We value clear interfaces, sensible defaults, accessibility, privacy, and software that does not make users work harder than necessary.

### Built across platforms

A project should meet users where they are. We aim to provide consistent experiences while respecting the strengths and conventions of Windows, Android, Linux, and the web.

### Practical over performative

We focus on solving meaningful problems with maintainable technology. Small, dependable tools are just as important to us as ambitious applications.

## Project status

Neptunium is an evolving organization. Some projects are experimental, while others are being prepared for stable releases. Before using a project in production, check its repository documentation for its current status, supported platforms, compatibility notes, and license.

## Get involved

Whether you are a developer, designer, writer, tester, translator, or simply someone with a useful idea, you can help Neptunium grow. Start by exploring our repositories, reading the contribution guidelines, opening an issue, or sharing feedback on an existing project.

We especially welcome contributions that improve accessibility, documentation, testing, localization, performance, and cross-platform support.

## Connect with Neptunium

- **GitHub:** Explore our repositories, follow project development, and contribute to open source.

- **Discussions:** Share ideas, ask questions, and help shape future projects.

- **Issues:** Report bugs and propose improvements with clear, reproducible details.

> If you are building with Neptunium software, we would love to hear what you are making.
